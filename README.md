# Homebrew tap for Yardsort

[Yardsort](https://github.com/joaoh82/yardsort) runs AI coding agents in parallel, each in its own
git worktree. This tap installs the macOS app.

```sh
brew install --cask joaoh82/yardsort/yardsort
```

The app is signed and notarized, and it updates itself — so `brew upgrade` leaves it alone unless
you pass `--greedy`. To remove it, including its data:

```sh
brew uninstall --cask --zap yardsort
```

`Casks/yardsort.rb` is generated by Yardsort's release workflow; please open issues and pull
requests in the [main repository](https://github.com/joaoh82/yardsort).
